# 管理员题库工作流

管理员登录后进入“管理设置 → 题库”。教师账号不能访问共享题库维护接口。

## 查看与检查

页面显示当前题库版本、题目数、可用数、受阻数、停用数及来源文档数。停用题也属于受阻，因此两个计数不能相加作为总题数。支持按题干文字/试卷名称、考点和状态筛选，打开题目查看题干、答案、解析、AI评级依据及管理员调整历史。没有配置题库时显示空态；上传初始化不要求容器内置题源。

“检查题库”重新执行当前来源、题答关联、模型证据、媒体及考点目录的程序检查，不调用LLM，不产生人工批准状态。检查发现的内容缺失、证据不一致或语义异常会阻止受影响题目参与组卷；结构化结果本身不能证明教学内容正确。

普通汇总、列表、详情及教师库存查询现在复用进程内已核验题库快照，避免每个请求重复读取全部 Word、图片和证据。每次复用前后检查来源、语义及引用证据目录中文件的身份、大小、权限和修改状态；原地改写、替换目录、增删文件或证据改变都会触发重新核验。存在符号链接或无法安全枚举依赖时不使用缓存，继续完整加载。缓存不跨进程和重启保存，首次读取仍需完整核验。

管理员调整每次从数据库读取，不缓存旧调整；导入发布、历史恢复和主动“检查题库”会执行完整核验。检查失败不会回用旧的成功结果。完整加载内部也只读取一次相同 Word 原件，逐题所需的摘要和原生内容检查仍保留。实现、失效反例和本机性能证据见 [共享题库读取优化](acceptance/bank-read-performance-v1.md)。

## 上传原始Word更新

1. 上传对应的原卷和解析DOCX，建议成对命名：`某次数学考试（原卷版）.docx`与`某次数学考试（解析版）.docx`，也支持现有“精品解析：”命名规则；同套试卷的主体标题须一致。
2. 每批2～40份，每份不超过30MiB，总计不超过200MiB，填写更新原因。宏文档、无效DOCX、歧义的同卷同角色文件和不完整配对被拒绝。
3. 后台保留其他试卷，新增新试卷、替换同套同角色原件，构建新的完整资料版本。执行拆题与答案关联、图片/原生公式提取、AI统一考点和难度、来源及语义证据校验。
4. **本版会对合并后的全库重新AI评级，消耗提交管理员的累计额度。** 缺DeepSeek配置、额度不足、渲染工具缺失或模型输出失败时，任务明确失败，旧题库保持不变。任务由独立Worker执行，关闭网页不会停止后台处理。
5. 检查通过的新题库自动生效，不需要人工审批。可预览受阻项并按来源或语义问题修复；不要修改AI调用证据文件来强行通过。

新的AI结果和原文版本不会无声继承旧版管理员覆盖；页面提示更新会清除当前调整，旧版本及其调整仍可恢复。完整重评是现有证据合同绑定整库SHA的首版边界，尚未实现只重评新增题的增量语义证据合同。

## 调整与版本恢复

可修改目标考点、前置考点、0～100难度分值、启停状态和备注，保存时填写原因。原AI结果始终保留，管理员调整明确标记为独立来源；结构损坏或题答关联未确认的题目不能靠修改标签变成可用。程序继续保证学生已学范围、前置知识闭包、去重、原题排除和题量配额。

题干、答案、公式和图形更新请在Word原件中修改后重新上传对应原卷及解析，产生新来源与评级版本。当前不提供会破坏原生数学结构的网页全文替换。

历史版本可以按原因恢复。恢复会生成新的当前版本，既有历史不删除。正在排队或执行的练习/导入如果遇到题库版本变化，会拒绝发布，需按当前版本重新提交；已经生成的下载文件和原有练习快照保留。

## 部署配置与边界

现有种子题库仍可只读挂载到`/bank`。网页上传生成的来源包、证据和版本位于`TEASSISTANT_DATA_DIR`所在共享私有卷，API和Worker通过同一数据库中的版本记录读取，无需手动修改容器题库目录或重启服务。迁移/备份必须同时覆盖数据库、共享私有文件及种子库。

生产部署由业务 Worker 编排、独立 Tools 服务执行 Chromium 渲染和文档转换；宿主机未配置远程工具时仍使用显式配置的本地转换器。本次读取优化只修改 API／业务代码，不改变工具镜像输入或 Tools 版本。

当前批次的离线、合成集成、真实种子库浏览和浏览器结果分别见`acceptance/`；真实DeepSeek新资料识别质量、完整ARM64镜像构建、ROCK 5B升级及老师教学价值不能由本机测试推导。
