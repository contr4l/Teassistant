# 管理员模型配置与累计额度

管理员登录后打开 **管理设置 → 模型与额度**。本功能只管理网页业务任务的 DeepSeek 调用；Codex CLI 仍是显式开发验证通路，不计入 DeepSeek 钱包。

## 首次配置

1. 填写 DeepSeek API Key 并保存。密钥留空表示保持已有密钥；保存后输入框清空，页面及读取接口不会返回密钥或片段。
2. 点击“检查余额”，显式调用官方账户余额接口。该按钮不发模型对话请求，账户余额也不作为本平台用户的费用分摊依据。
3. 新账号创建时默认一次性获得 **10 元**额度。管理员可在“新用户默认额度”中调整（允许0），只影响之后创建的账号，已有用户不补发或改额。需要更多额度时选择用户并“追加额度”，只增加总额度，不重置已用金额，没有日/月重置。
4. 老师提交分析时，后台逐次检查额度并记录用量。学生材料、老师账号、任务归属仍由原有权限约束。

本批工程限定官方 `https://api.deepseek.com` 与已适配视觉模型 `deepseek-flash`，不能在这里填写其他供应商或任意地址。配置固定单价可调整，金额以人民币元输入，最多六位小数。当前默认参考值为每百万 token：缓存命中输入 0.04 元、未命中输入 2 元、输出 8 元；这是估算参考费率，需由管理员根据适用价格维护。

密钥和费率保存到 `TEASSISTANT_DATA_DIR/admin-model/deepseek.json`，目录权限 0700、文件 0600，原子写入。API 和 Worker 必须共享私有目录及数据库。管理员配置优先于 `DEEPSEEK_API_KEY` 环境后备；没有配置文件时使用环境变量，密钥不会写入数据库、任务快照或启动参数。服务器上该文件仍含明文凭据，备份与读权限按私有资料管理，不进入 Git 或镜像。

保存后，后续启动的模型处理读取新配置。主分析子进程的多阶段与重试使用启动时快照，独立教师报告启动时另取快照；已开始的处理不会中途切换密钥或费率，旧账不重算。与提示词“提交任务时冻结”是不同生效边界。

## 额度如何扣减

`可用额度 = 累计总额度 − 已用额度 − 预占额度`。

默认额度及版本保存在共享数据库，升级/重启不覆盖管理员已保存值。账号、初始钱包和发放记录在同一事务创建；读取钱包、登录或列表不会触发发放。升级前的账号即使尚无钱包也维持原余额，不按新默认值补发。修改默认值带版本检查，其他管理员已修改时需刷新；赠额与设置更新保留审计。

每次 DeepSeek HTTP 请求发送前，共享数据库先原子预占，重试也单独检查。按本批核准输入上界 1,048,576 tokens 与该次最大输出计算保守预占；默认参考价与最大输出 8192 时，单次预占为 **2.162688 元**。即使实际费用通常较低，可用额度低于该次预占也不能发送请求。并行阶段会同时占用各自的额度，管理员应据实际并发和任务量追加额度；预占不是最低实际消费。

有效 usage 返回后，按该次冻结费率估算已用金额，释放预占差额。业务 JSON 或结构校验失败但有有效 usage 的请求仍会结算。费用向上取整到微元，数据库采用整数微元，不用浮点数累计。

超时、网络异常、缺失或无效 usage、进程中断可能无法确认供应商是否消费，预占保留为未知，不按零元处理，也不因租约过期自动退还。用量超过核准上界或预占时，账户冻结并待核实，不能继续透支。

管理员在“待核实预占”中核对调用后，填写 0 至预占金额之间的确认估算额与原因，显式记账并保留审计与幂等记录。这是人工确认金额，不会伪造供应商 usage。仍在有效任务租约内的活跃预占禁止核实；任务中断、结束或租约过期后提供核实入口，必须先确认旧请求状态。全部异常溢出处理后解除相应冻结；其他未知预占仍保留。列表当前最多展示 100 条待核实记录。

## 昨日费用口径

昨日按 **Asia/Shanghai 北京时间自然日**，以请求开始时间归属，存储时间为 UTC。按用户的已结算估算小计降序排序，并列展示请求数、未知数和待核实预占。

费用是“**本平台记录的请求 token 用量 × 该次配置固定单价**”，并非 DeepSeek 官方账单。没有自动按峰谷或节假日切换价格；缺缓存细节时按未命中输入估算。有未知用量时总估算显示未知，已知小计不能代替完整花费。核实历史请求会更新其原开始日统计。

首次升级记录采集开始时间：上线前的昨日显示未采集，当日中途启用显示部分采集，不回填假零。共享 DeepSeek 账户在平台外产生的消费不会进入这里，也不能从账户余额差额反推给老师。独立开发 CLI、题库批处理等未绑定网页用户的离线通路不计入本账本。

初始费率与余额接口参考：[官方中文价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)。参考核对日期为 2026-11-12，不承诺今后价格不变。

## 升级与验收边界

本批增加独立账本及默认额度表，启动初始化采用 `create_all`，不修改旧学生与考试记录；升级应同时重启 API 和 Worker，并备份数据库及共享私有目录。Docker 镜像加入时区数据，操作见 [部署指南](deployment.md)。可以先不在 `.env.deploy` 填写密钥，启动并创建管理员后在网页配置；用户仍须有足够可用额度才可真实分析。默认额度增补验收见 [本批记录](acceptance/default-user-credit-v1-execution.md)。

本批检查使用合成账号、合成密钥和 MockTransport，完成静态、单元/集成、真实子进程共享账本及 Chromium 页面验收。它不代表真实 DeepSeek 扣款对账、生产 PostgreSQL 并发、Docker 实建部署或教师教学价值已经通过。证据见 [执行记录](acceptance/admin-billing-v1-execution.md) 与 [独立检查](acceptance/admin-billing-v1-review.md)。
