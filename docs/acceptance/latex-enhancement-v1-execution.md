# MathType 转换增强执行记录

日期：2026-11-12。按[增强合同](latex-enhancement-v1-contract.md)实施，对应 FR-15 / DEV-004、DEV-404。总设计及集成为 Sol/high，公式转换和诊断由实际可用的 gpt-6-luna/high 并行实施，Sol/high 独立验收；没有将实际模型写作不存在的 6.1 Luna。本批无 LLM 识别调用、新供应商或新依赖，不自动提交。

## 改动

- `math_latex.py` 的转换身份升为 strict-v2。只按显式 MTCode U+03C0 补 π；不按字体槽位猜字。
- 绝对值归一化限定为已确认的 tmBAR 双边变体、零模板专用选项、完整非空正文 LINE、合法 COLOR/FULL 控制和末尾有序的纯 EC07/EC08 围栏字符。错误字体、字符顺序、缺失、额外数学槽位、附加数学修饰或未知变体均拒绝。独立反例发现的“带点修饰围栏被删除”已改为拒绝。
- `diagnose_latex_bank.py` 只读扫描原库全部行，保留 blocked 行、题目/对象/出现次数的独立分母、来源字段及绑定错误；结果写入新目录。可加载可信的冻结旧转换器作比较，候选结果绑定实际源码 SHA。
- 实际样卷检查发现题干与整块作答区跨页分离，`latex_exporting.py` 加入局部不分页约束，模板身份升为 latex-exam-v2。没有把整份长题强制放入不可分页的盒子。

MTCode 身份与字体位置的区别依据 [Wiris Font knowledge](https://docs.wiris.com/reference/font-knowledge)。EC07/EC08 的本批规则依据原生 tmBAR 结构、厂商历史格式资料和绑定原预览的对照；本次没有从可公开访问的官方码点表直接核准这两个私用码，不宣称通用私用字符映射。

## 固定失败题单的真实验证

冻结旧转换器、题库、语义文件及原失败诊断后，从历史任务只读重建同一份 10 题、相同顺序的选题。新派生快照明确标记合成学生进度，不改写历史任务或学生标记；题目和公式来自真实原 DOCX。

| 指标 | 旧转换器 | strict-v2 |
| --- | ---: | ---: |
| 不同原生对象 | 53 | 53 |
| 可转换对象 | 46 | 53 |
| 不支持对象 | 7 | 0 |
| 不支持出现次数 | 8 | 0 |
| 受影响题目 | 6 | 0 |

7 个恢复对象分别从原 ZIP/OLE 和绑定预览核对，覆盖科学记数法定义中的绝对值、计算题的负号、根式、分式、指数及 π。学生卷 24 次公式、教师卷 34 次公式，共 58 次出现，均使用原生数学排版；题单未替换。

另对上一版成功样卷的 100 个不同对象、187 次出现重建公式目录，新旧 MathML、LaTeX 内容逐字一致。本次 10 题中原先成功的 46 个对象也逐字不变。转换目录仍执行来源重验，不能拿旧身份目录伪装新转换结果。

## 全库覆盖比较

相同原库共 200 题，其中语义及来源筛选后的 eligible 为 176 题，blocked 为 24 题；全部原始题保留在扫描中。187 题含公式，另 13 题没有原生公式。以下仅统计实际导出的题干、答案和解析三个字段：

| 指标 | strict-v1 | strict-v2 |
| --- | ---: | ---: |
| 不同完整原生对象 | 2,652 | 2,652 |
| 转换成功对象 | 2,233 | 2,288 |
| 不支持对象 | 419 | 364 |
| 公式出现总数 | 5,137 | 5,137 |
| 转换成功出现次数 | 4,580 | 4,644 |
| 不支持出现次数 | 557 | 493 |
| 含不支持公式的题数（原始 200 题内） | 102 | 88 |
| 含不支持公式的 eligible 题数（176 题内） | 85 | 71 |

因此新增支持 55 个不同对象，减少 64 次失败出现、14 道受影响题；原先成功的 2,233 个对象没有转为失败。没有声称全部 200 题可导出；55 个对象是工程转码覆盖增量，其中本批原件逐式语义对照的固定分母为上述 7 个恢复对象。

诊断另外扫描解析版重复题干 `analysis_stem_blocks` 的 1,249 次出现：四字段总数为 6,386，不能拿这个数作为实际导出分母。独立检查直接从 16 个原 DOCX 重算所有 SHA 和 6,386 条绑定，逐项多重集与诊断结果相等。所有来源绑定通过，0 条未核准来源被计为成功。

候选在实际导出字段仍有题干 77 次、答案 28 次、解析 388 次不支持，共 493 次；字段题数可以交叠，不能相加当独立题数。全库原件与转换器摘要、逐项报告 SHA 比较保存在 `candidate-bank-scan-final/comparison.json`，旧报告保留。候选转换器源 SHA 为 `7ce7f4b0d5823fafe4fd3594d57fb9b1925ae2e84cafb7414732d45e80fab9fa`。

## 实际 PDF

两种版式分别生成学生及教师 PDF，实际调用 XeLaTeX，并检查最终 4 个 PDF 共 9 页：作答学生 2 页、紧凑学生 1 页、教师各 3 页。最终版第 7 题及其全部 7 条作答线一起位于第 2 页。紧凑学生和两份教师 TeX 相对首轮重放逐字不变，PDF 页面逐像素一致。

这份题单没有几何图，最终 PDF 图像出现次数为 0；数学使用嵌入字体，未拿原公式 PNG 代替。几何图一般支持路径及上一版包含几何图/表格的验收仍见原 LaTeX 导出记录。本批未新增几何图重绘能力。

私有复核产物位于 `work/latex-enhancement-v1/`：冻结输入摘要、原件对照、重放输入、候选目录、全库扫描、实际 PDF、回归日志和独立检查。最终样卷为 `replayed-pdf-v2/`；首轮重放保留用于分页反例，不覆盖。

## 检查与边界

`make check`：ruff 通过，606 tests passed，1 条既有 Starlette/httpx 弃用警告。随后诊断源码身份及导出范围统计的最后改动另补跑 3 项定向测试与 ruff，通过；未重跑不相关前端构建。

这是原生数学转换和排版的工程验收，尚非全库逐题数学正确性、任意 Word 兼容性、教师满意度或教学价值验收。剩余不支持的类别包括部分 Unicode 符号、带非英文文本的公式、不同围栏控制组合及矩阵对齐属性；不能将未知符号置空或近似替换后声称成功。后续补表仍需作用域、修饰和实际 PDF 验证。

当前本地预览保持 18072 可访问；在确认无排队/运行任务、核准保存进程的解释器、脚本和工作目录后，仅重载空闲 worker 以使用新转换器。原登录信息、数据库及原材料保留，没有重放修改用户数据。
