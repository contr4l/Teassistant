## 实际分工与实现

Root 负责合同、配置私有存储、HTTP 计量、子进程桥接、网页 API 和既有界面集成、文档与集成验收。用户指定 Sol/high 总设计与验收、Luna/high 并行；账本和前端实际使用可用的 `gpt-6-luna/high`，没有把它冒称 `GPT-6.1 Luna`。独立检查实际为 `gpt-6.1-sol/high`，见 [独立报告](admin-billing-v1-review.md)。共享目录按文件归属实施，Root 在实现者冻结后补充活跃预占保护与中断恢复接口。

- `model_settings.py`：管理员密钥仅私有 0600 文件，目录 0700，原子替换/写锁/配置版本冲突检查；官方 endpoint、Flash 模型、固定费率。GET、错误响应、任务快照和 argv 不含密钥。
- `model_billing.py`：共享数据库累计钱包、每次请求尝试与追加审计；整数微元、向上取整、事务及幂等。每次实际 HTTP 前预占，重试独立检查，未知保留、超界冻结、人工核实及归属原请求日的统计。
- `model_runtime.py`：绑定服务器 owner/job/有效租约；MeteredTransport 在业务 JSON 校验前记录 usage；主分析子进程经内部环境上下文使用同一账本，不能静默绕过计费。报告与分析共用用户累计额度，Codex 开发验证不计入 DeepSeek 费用。
- `web_api.py`、`web_jobs.py` 与 CLI：管理配置/余额检查/昨日排行/累计钱包/增额/未知核实，admin+CSRF；教师仅查自己的钱包。有效任务租约内的 reserved 禁止核实，中断遗留预占提供显式有原因核实入口，不自动退额。
- React 新增“管理设置 → 模型与额度”：密钥保存清空、参考费率/最大预占、模拟/真实余额检查入口、昨日估算排行、覆盖状态、总/已用/预占/可用额度、追加额度与待核实处理。原有提示词、账号、学生及考试流程保留。
- Dockerfile 增加 `tzdata`；PRD、架构、计划、README、网页及部署说明同步。没有新增 Python 依赖，无须变更本批 lock 内容。

配置在每个模型处理单元启动创建适配器时冻结：已开始的主分析多阶段与重试保持其版本，独立教师报告另取启动快照。保存后影响后续启动处理，不宣称所有在途 HTTP 即时换 key 或改价。每次尝试记录实际使用的版本，历史不重算。

主要反例包括：两个真实独立解释器争抢最后一份额度只能一个成功；SQLite BEGIN IMMEDIATE 防止预占半提交；不足额度拒绝发生于网络发送前；超时后重试单独门禁；有 usage 的无效业务 JSON 仍扣估算费用；无效、冲突、负/bool usage 不免费退还；微元向上取整；未知预占与超界冻结；重复加额/结算/核实幂等；历史价格冻结；北京昨日半开区间、月底与未采集状态；教师越权和缺 CSRF 拒绝；含密钥的错误输入不会被 422 回显。

真正的 CLI 桥接测试启动新 Python 进程，连接父服务同一 SQLite 文件，经 `adapter_from_environment` 与 MeteredExamAdapter 调用 MockTransport。业务 schema 无效但有效 usage 已结算 **0.002204 元**，20 元初始额度变为 **19.997796 元**、预占归零；stdout/stderr 无合成密钥。该测试证明子进程计量接线，不是一次真实模型识别。

浏览器独立实例使用合成管理员、两位合成教师、合成密钥及费用，provider HTTP 全部 MockTransport，未访问真实账户。真实交互覆盖登录→管理页、写密钥及输入清空、模拟余额检查、昨日已知费用降序/未知项、追加 10.000001 元、带原因核实未知预占。最终桌面截图 1440px、手机 390px 已亲自检查；手机表格允许内部滚动，没有整体页面横向溢出。截图和凭据保留私有 work，不进入源码。
