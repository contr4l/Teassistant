# 教师网页与提示词管理执行记录

日期 2026-11-12。依据 [冻结合同](web-loop-v1-contract.md)、PRD FR-05～17 和 UC-02～09。实际实施 Sol/high 集成与独立验收、gpt-6-luna/high 并行实现；没有将实际可用 Luna 改称 6.1 Luna。本批未自动提交或推送，也未修改旧真实题库、原件和历史模型结果。

## 本批可运行能力

React/TypeScript 网页接入 FastAPI，覆盖账号登录/注销、老师归属隔离、学生资料与已学考点、考试与手机多图/PDF上传、材料角色和顺序、持久任务、逐题分析、授权原图与证据框、转录/关联局部修正、组卷、预览、题答下载及老师反馈。管理员可以创建教师，编辑 layout、paper、reference、response、diagnosis、report 六段说明，保存历史并回滚。

提示词在提交时冻结，公共来源约束、Schema、考点白名单、进度、配额和去重保持程序校验。report 是实际模型阶段，不再用单份手写 HTML 报告代替自动生成。人工修正生成追加版本，重新识别时按历史顺序恢复能够安全绑定的覆盖；无法转移时保留已发布修正、明确失败。重复同题编辑的历史重放另有回归用例。

SQLAlchemy 保存用户、密码摘要、会话、业务记录、任务及提示词版本。后台执行独立于 HTTP/浏览器；租约、资源与学生/考试版本通过事务检查后发布指针。进度更新后旧练习链接隐藏，直接下载也返回 409。失败和未确定不填充示例成功；题量不足展示缺口，未放宽进度。

本地预览使用 SQLite，生产 PostgreSQL/Celery/Redis 配置另提供 Compose。业务仅 DeepSeek；显式启用的 Codex CLI 只用于开发验证，无自动 fallback。

## 检查发现与关闭的问题

独立反例及实际点击关闭了：创建考试缺题数、进度版本类型错配、局部转录错误提交成重关联导致422、异步旧考试结果污染视图、提示词保存与任务上限不一致、私有路由错误落入SPA、更新进度后旧下载未阻断、CLI初始化密码空格被HTTP裁剪、刷新无法找回练习，以及公式图片尺寸被清理后显示过大。

预览保留受限 MathML 与数值尺寸；iframe禁止源脚本、表单与顶层导航，CSP仅允许内嵌图片和样式。长解析可内部滚动，不通过截断正文掩盖。报告事实、解释与待确认分开，修正后报告重新生成，不保留已失效的旧说明。

原生公式并非全库均可转为 LaTeX。前两轮 HTTP 试验遇到未支持公式，正确失败且未发布半套下载；随后明确选择 Word 模板转换，不是自动降级。第3轮已输出但合成标志尚未贯穿产物，保留为历史，修正后第5轮重导。第4轮联调发现新字段检查误插入 inventory，已修复并补复验；全部失败与修复后的证据分开保留。不得将本批写为“全库 LaTeX 已支持”。

## 运行与边界

启动、初始化管理员、配置与部署见 [网页应用说明](../web-application.md)。本机实际预览与隔离测试服务使用不同数据库；隔离服务在验收后停止。实际本机预览开放可选 Codex 开发通路，教师自行提交才调用模型；生产默认 DeepSeek。

目前以本地闭环工程通过为结论。FR-14 单题替换、删除和排序尚未交付；考试原题与题库尚无全量可靠身份桥接，界面明确提示核对，不宣称全部自动排除。网页主要按单次考试展示分析，完整的最近三次学情聚合展示仍需后续接入；既有本地汇总模块不等于该网页能力已验收。

本机 Docker daemon 不可用，未启动/构建 Compose、生产 PostgreSQL/Redis 或外网 HTTPS。Docker内Node24、服务器转换器/字体、备份恢复和真实手机网络仍须独立部署验收；当前验证是本机浏览器390px视口。没有真实老师评价，不以合成反馈、测试通过或一次报告生成宣称节省时间或完整MVP通过。
