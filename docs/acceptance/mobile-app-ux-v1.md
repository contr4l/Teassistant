日期：2026-11-14。依据：用户 2026-11-14 要求（整体 UX 贴近移动 App；电脑保留左侧导航；手机组卷并下载成品 PDF 列入本期）、[PRD](../PRD.md) 1.1（已同步更新）、[设计约定](../ui-guidelines.md) 第 8 节、[手机端与入口优化建议](../mobile-optimization.md) 第 0 节。

结论层级：**界面交互改版完成（本地合成数据、无头浏览器检查）**。不等同于真机验收、MVP 功能验收或老师价值验证。

| `frontend/src/styles.css` | 手机端布局与尺寸 |

未改：后端、API、数据结构、依赖。

主要交互：

- 五个入口 工作台 / 考试分析 / 学生档案 / 组卷 / 我的，两端名称、顺序一致；手机为底部标签栏，电脑为左侧栏（账号行进入“我的”，不再一点即退出）。
- 页面位置写入网址：手机返回键回到上一层；切换标签不叠加历史，任一标签根页返回到工作台；弹窗打开时返回键先关弹窗；刷新停留原处。
- 详情页只读取网址中的 id；id 不存在显示“找不到”，不回退到其他记录。
- 手机详情页的唯一主操作在底部固定栏；页面内按钮为描边样式；按钮不可用时写明还差什么并给出入口。
- 上传：“拍试卷”“拍学生作答”与“从相册或文件选择”；缩略图与“第 N 页”；逐文件“上传中 / 失败（重试、移除）”；上传队列保存在 App 层，切换页面后仍显示进度；图片长边 ≤2560px、JPEG 0.85 压缩（实施默认，需真实卷面确认）。
- 未保存的新建考试、新增学生、学生资料修改：页内导航、标签、返回键（含手机系统返回键）先确认；刷新或关闭页面由浏览器提示。组卷设置按学生暂存在 `sessionStorage`。
