## 全量发现的目录缺口与迁移门禁

90 点基线全量运行中，`pair-173056743099-q16` 暴露真实目录缺口：整除、公倍数与真假条件的数值分类推理没有合适的具体目标。独立看过原题，模型的推理与提高层次判断有依据，没有为了通过白名单而硬套概率或规律标签；但返回 assessed 且目标为空，被合同正确拒绝，该批 4 题保留为技术失败。pilot 通过不表示目录已覆盖所有 200 题。

后续还出现纯真假陈述题缺口，以及已成功但 warnings 提示缺少正多边形与圆专题的记录。审查允许在任何 V2 响应前新建目录 v2，新增三个特定基础/方法点：整数整除、奇偶性与公倍数；真假陈述约束下的分类/排除；正多边形边长、外接圆及边心距。旧 90 个 ID、名称和前置完全不变；整除基础注明跨学段补充，方法粒度及本批专题拆分不冒称官方稳定 ID 或已完成教学校准。真假推理不强制有理数前置，也不泛指普通几何分类。不要求机械重跑所有 200 题，但不能静默把旧响应说成模型已经看过新目录。实施和验收须满足：

- 旧子图使用成功 bundled run 内的 cff29… 目录快照，不能混用旧失败 run 的 ebf… 目录。旧 ID、名称和前置逐项保持一致；原件、输入、提示模板和评分规则保持可兼容含义，否则拒绝迁移。
- 原成功记录须重查 source hash、原始 call 中题目唯一性、raw 与 sidecar 一致性、证据、白名单及新闭包。原 assessment 和模型 warnings 原样保留；每行明确原 assessment 目录、model input catalog SHA、原 run/call/raw 摘要、模型与二进制身份，同时另存当前 validated/index 目录 v2 和 `carried_forward_not_semantically_reassessed`。
- 所有基线失败及受影响候选进入固定 affected manifest；候选结合全部原题干与原响应中整除/奇偶/公倍/公因/余数、真假约束、正多边形与圆等依据筛选，不能只处理空标签。普通几何分类不自动追加一个真假方法标签。
- 进入受影响集合后，必须得到新的 v2 响应或显式失败/等待；新调用失败不能回退旧成功评分来掩盖。兼容迁移只证明旧标签在新 index 合法，不能证明新增点的映射完整性已经重新推理。
- 最终 direct-v2、carried、failed、not-attempted 等类别互斥并合计固定 200；分别报告新模型重评数与兼容迁移数，保留旧 run、旧目录和全部失败。程序迁移说明与模型内容说明分开，不能伪造模型证据。

这些门禁按[目录 V2 迁移合同](semantic-catalog-v2-contract.md)实施，独立负例与最终来源审计结果见下。

## 限制

200/200 表示有真实模型来源、结构与当前白名单校验完成，**不是考点或难度准确率 100%**。93 点仍是工程目录草案；177 个兼容项未在新增目录下重新推理，新增点对所有题目的映射完备性尚未证明。20 题 warnings 是模型疑点，不一律等同于已裁定的源题错误；原件不自动改写，也不新增人工题库审核。

难度为 `junior-math-demand-v1` 的模型初评，未使用老师锚题或学生真实得分校准；目录亦未与目标老师教材进度逐章对齐。侧附结果不等于现有业务 `Question` 已接入、数学导出适配已通过或正式可组卷题库已经发布。
