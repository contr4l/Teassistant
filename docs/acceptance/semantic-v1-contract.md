# 考点统一与难度评级首批合同

日期：2026-11-11。对应 FR-03/04、DEV-003/202；用户显式选择 **Codex CLI 开发验证**，不新增业务供应商或自动回退。真实输入固定为来源 V3 的 200 个大题及原件摘要，不覆盖来源 V3、旧库或真实文件。

## 目标与证据边界

建立非合成、版本化的初中数学工程考点目录草案，依据教育部《义务教育数学课程标准（2022年版）》7～9 年级内容组织。稳定 ID、名称和前置有向无环关系用于本轮统一；工程拆分粒度与前置边由本项目编制，不声称教育部或湖南省发布了同名标准 ID。尚未与目标老师教材及进度逐章核对，不能称为正式湖南目录。

所有结构成功题均进入相同语义流程，有无来源词条不影响是否调用模型。来源词条仅是参考证据。输入包含完整可读题干、公式和图形，必要的答案与解析；未确认题答关联的 7 题不将不确定答案当成可靠依据。先固定代表性小样验证，再扩大到全部 200。

难度按现有 0～100 分、基础 0～39／提高 40～69／挑战 70～100 的工程分段。版本 `junior-math-demand-v1` 评估完成整道题所需的知识综合、推理链、运算负担与关键构造，不能用题号、篇幅、失分率或来源名直接评分。评分是模型推断，尚无学生实测得分率、老师锚题或等级校准，结构成功率不能改称难度准确率。

## 共享输出与程序规则

`backend/app/semantic_contracts.py` 是本阶段侧附标记的唯一共享类型；不修改旧 `Question` 或伪造页码/bbox。模型批响应 `SemanticBatchResponse.assessments`，每项包含 question_id、status、point_ids、prerequisite_ids、difficulty_score、reasoning、point_evidence、warnings。assessed 必须有合法目标、整数分及逐标签依据；insufficient_evidence 必须清空分数和标签并说明原因。

模型不能指定来源摘要、目录版本、评分版本、运行模式或 ready。程序校验固定 ID 集合、重复/额外/漏题、结构、考点白名单、证据覆盖、前置闭包与无环目录；补足目录前置闭包由程序执行。未知标签及非法分数失败留在分母，重试有界且显式，不回退到合成结果。保存原始响应、输入摘要、实际配置模型、attempts、用量可得性、耗时和错误分类，不把模型自报名称作为服务身份。

采用来源 V3 上叠加的新语义结果目录（侧附 JSON、CSV 和 HTML），保留所有 200 个固定 ID，分别显示成功、失败、等待、未尝试数及 7 个关联未确认标志。开发验证结果不自动发布为业务 ready。目录/提示/评分版本或源数据改变时，旧结果保留并失效，不能静默复用。

## 文件归属与验收

- Root：本合同与 `semantic_contracts.py`、统一批处理 CLI、目录整合及实际试跑、展示和证据。
- 实现 A：`semantic_models.py` 与对应测试，显式 DeepSeek/Codex 通路，对新批响应提供模型调用，复用既有配置/安全边界；不得调用真实服务。
- 实现 B：`semantic_inputs.py` 与对应测试及渲染 CLI，来源题目到可读图片/文本与输入 manifest，保留完整数学和图形；不得执行模型调用。
- 独立设计/验收：先冻结样本与反例，再检查目录、响应校验和完整输入，独立执行关键反例及真实小样内容核对，报告推断与未知。

主设计验收沿用 `gpt-6.1-sol/high`，实现实际为 `gpt-6-luna/high`；不可用的 `gpt-6.1-luna` 不作实际记录。检查未知标签、重复/漏题/额外 ID、布尔/越界分数、错来源复用、被改变的输入图、未确认关联、无来源词条、白名单与前置循环、缺图截断、模型永久错误和无凭据显式失败。运行 `make check`；真实试跑的分母与调用次数独立于合成测试。
