## 来源输出 V2

新构建使用 `schema_version=source-bank-v2`，保留原题目块与来源字段；旧 V1 题库及原输入不覆盖，新目录构建并检验后单独交付。

| 内容 | 合同 |
|---|---|
| 文档身份 | 按 `(pair_id, role, sha256)` 建唯一记录，同内容的同用途副本保留 aliases/source_copies 和原件；不同上下文的同字节资料使用不同记录 ID，避免单值 pair/role 关联丢失 |
| 独立清点 | 原卷、解析分别发现题号与范围，再以并集关联；解析额外题不能被原卷号码过滤或并入上一题；题数声明按章节范围核对，未知预期明确为空 |
| 题答确认 | `association_status=confirmed/unverified`；确定一致才 confirmed，不把仅图像字节差异说成确证错配；unverified 必须有原因并阻止整批完整成功，仍不具备组卷资格 |
| 答案 | `answer_available` 表示剥离标记后有实际可用内容；答案只有标签不计有答案，解析可选 |
| 段内分割 | 同段多个答案/解析标记按位置拆分，保留文本、公式与图片顺序；片段有来源范围或索引，不重复引用媒体 |
| 数学 | OMML 保留原 XML 和 occurrence；支持的结构生成安全 MathML，未知结构可见占位并明确失败；新增 `omml_occurrences`、`source_omml_count`、`rendered_omml_count`，合并块与文件计数保持一致 |
| 文件失败 | `failed_documents` 独立记录不可处理文件；不将缺正文的伪 document 塞入索引；原文件及失败原因保留在私有构建产物 |
| 批次 | `batch_status=succeeded/partial/failed`；计数含 input_files、duplicate_files、failed_files。无题为 failed；局部失败或未确认关联为 partial；重复输入成功归并本身不算失败 |
| 来源资格 | `practice_ready=false`，未执行难度仍为 null，不填占位评分或假坐标 |

`render_omml(xml.etree.ElementTree.Element)` 返回 `html`、`text`、`source_xml`、`supported`、`issues`。转换器不执行嵌入对象、脚本或网络请求；浏览器仅允许生成的数学标签及受限属性。支持范围须由合成反例及实际浏览检查验证，不宣称已完整转换所有 Word 数学类型。

## CLI 与指纹

构建 API 返回完整摘要，仍在临时目录完成后发布新目录；已有输出拒绝覆盖。命令退出码为 0（来源构建完整成功）、3（有可用/诊断产物但部分完成）、1（构建失败或无可提取题目）。不以诊断目录存在伪装题库成功；不保证持久任务恢复，本批仍是本地构建。

指纹升级为 `source-structure-v2`：规范化文字和图片字节之外，保留表格行列/合并及数学结构。不再将不同表格布局视为同一份精确提取内容；没有题干的记录不产生空题干通用指纹。该指纹仍不等于语义近似去重，不能直接宣称已实现跨学生卷原题身份匹配。

## 验收

先将已复现反例转为持久合成测试，保留正常一致题及复杂段内媒体作为正例；修复后独立执行关键反例。然后对现有 16 份资料在新目录重建，报告预期 200 题的提取、关联确认/未确认、结构失败、媒体与表格，不能通过一律标失败或未确认来代替实现。

复核旧题库和 16 个源文件的字节摘要，确认未覆盖；核对新产物原件、题号范围和媒体出现顺序，实际检查 MathML 与旧 MathType 预览。`make check` 与独立验收均通过后记录真实结果，不借用历史通过数。
