# 界面去模板化改版 V1：执行与验收

日期：2026-11-12。依据：[改版提示词](../ui-refresh-prompts.md)、[设计约定](../ui-guidelines.md)。关联既有 UC-02～09 的网页体验，本批改表现层与文案，不改 API、数据结构与后端；应用户要求新增前端依赖 KaTeX 用于公式渲染。

结论层级：**界面改版完成（本地合成数据浏览器检查）**。不等同于 MVP 功能验收，也不等同于老师价值验证。

## 1 范围

| 文件 | 改动 |
|---|---|
| `frontend/src/App.tsx` | 登录、侧栏、工作台、学生档案、考试分析、组卷、管理页面的结构与文案 |
| `frontend/src/styles.css` | 删除装饰与无引用样式；字号、对比度、字距、圆角、阴影收口；新增表格、列表、步骤样式 |
| `frontend/src/UsageGuide.tsx`、`usage-guide.css` | 使用方式文案、术语与样式 |
| `frontend/src/MathText.tsx`、`frontend/package.json`、`frontend/pnpm-lock.yaml` | 新增 KaTeX 公式渲染组件与依赖 `katex@0.19.1` |
| `frontend/src/api.ts` | 错误信息映射为中文（`readableError`、`readableJobError`），网络失败提示；请求逻辑不变 |
| `frontend/src/AdminModelBilling.tsx`、`admin-model-billing.css` | 小标签移到标题下方说明，额度说明改写；字号、对比度、圆角、阴影收口 |
| `docs/ui-guidelines.md`、`docs/ui-refresh-prompts.md` | 新增设计约定与提示词顺序 |
| `docs/web-application.md` | 跳转名称随术语表更新，链接设计约定 |

未改变的行为：所有 API 请求、参数、轮询、上传顺序、修正提交逻辑、组卷请求、权限判断。交互变化：

- 考试缺少试卷或学生作答时，“开始分析”按钮直接禁用并说明原因。原先可以点击，再弹出同样的错误提示；前端检查条件不变，后端校验不变。
- 工作台考试行可直接打开对应考试，原先只切换学生和页面。
- 分析通道选择只在服务端开启开发通道（`allow_codex`）时显示；默认部署仍固定为 DeepSeek，与原先只有一个选项的行为一致。
- 组卷页未勾选为已学的考点不可勾选（后端原本即拒绝）；反馈表单无默认值，须选择后才能提交。
- 工作台“新建考试”直接打开创建表单；原图、修正、历史弹窗支持 Esc 关闭与焦点约束。

## 2 诊断（步骤 0）

基线截图：本地 `/tmp/tea-ui/shots/before/`（未入库）。主要问题：

1. 首页套用“问候＋口号大标题＋渐变横幅＋三张指标卡＋最近动态＋快捷入口”模板；横幅含轨道圆环、CSS 拼贴纸张、✳ 符号。
2. 登录页左栏为宣传文案、假分页 `01 / 04`、英文副标 `TEACHER DESK`。
3. 几乎每个区块叠加 eyebrow 小标签＋标题＋说明，部分再加徽章（“档案已保存”“权限隔离”）；“第一步”与 `01 / 03` 重复。
4. 大量 7–11px 文字，灰字对比度普遍低于 4.5:1；中文标题负字距 −0.04～−0.07em；Inter 排在中文字体前，混入宋体。
5. 列表行均配“淡色方块＋图标”；指标卡与快捷入口颜色与含义无关；多处 Sparkles 图标。
6. 文案：口号与价值升华、“把……放在一起”句式出现 4 次、“安全上传/授权原图/由服务端校验”、教师界面出现“分析通路/DeepSeek · 业务模型/考试信号/JSON 合同”。
7. 数据误导：首页“考试记录 3”和最近列表其实只是当前所选学生的考试，未标明。
8. 既有缺陷：组卷“学生卷版式”单选按钮被隐藏，看不出选中项；题量缺口显示内部考点 ID；考点可用题数重复显示两次。

## 7 已知限制

- **公式可读：已处理（实现者验证，未经独立复验）。** 用户于 2026-11-12 改为要求渲染公式，新增依赖 `katex@0.19.1`，规则见[设计约定](../ui-guidelines.md)第 6 节。浏览器检查（合成数据、模拟分析接口，1440px 与 390px）：26 处公式渲染；方程组 `cases` 正确；错误公式 `\frac{a{b` 以红色原文显示且后续文字保留；`\href{javascript:...}`、`\url` 未生成任何链接、无弹窗；公式内中文、`\$`、未闭合 `$` 按预期；无横向滚动；修正弹窗实时预览正常。截图 `math-*.png`，脚本 `/tmp/tea-ui/verify_math.py`。代价：主 JS 包由 251 KB 增至 517 KB（gzip 77 KB → 158 KB），Vite 提示超过 500 KB 分块阈值；KaTeX 字体按需加载。练习卷预览中不支持的 MathML 显示可见提示“以导出文件为准”，导出文件对这些公式的处理本批未验证。
- 工作台只显示当前所选学生的考试，因为现有接口按学生查询；界面已标注所属学生并可切换。
- 字号、对比度、圆角、阴影数值已由用户于 2026-11-12 确认采用。
- 未在真实手机浏览器、真实卷面或真实模型结果上检查；分析结果、原图、修正、组卷结果与失败仅以模拟接口验证；真实哈希 `page_id` 下的页码显示未验证；未做读屏软件测试；请求本身没有超时机制。
