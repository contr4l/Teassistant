日期：2026-11-11。用户授权继续执行题库评估后的开发，本批完成 [修复合同](ingestion-hardening-contract.md) 对应的来源录入正确性工作。按合同分文件协作，独立验收见 [验收报告](ingestion-hardening-review.md)。

## 交付范围

- 原卷与解析独立清点后关联，额外解析题、缺中间答案及编号冲突不再静默污染前一题。
- 确认关联时同时比较规范化文字、原尺寸精确 RGBA 图片和 OMML 结构；保留小数、符号等数学含义。不能确认则标 unverified，不假称确认错配，也不增加人工批准。
- 答案按实际内容判断，解析可选；同段答案/解析标记按位置切分，图像、OLE、OMML occurrence 跟随各自片段。
- 同上下文重复文件合并记录并保留所有原件副本；跨上下文记录仍有独立身份。坏文件单独保存失败证据，其余来源可继续构建；无题输出为 failed。
- 基本 OMML 分式、根式和上下标保留源 XML 并以安全 MathML 显示。未知节点、未验证样式和 n-ary 布局显式失败，不再静默丢失。
- 指纹加入表格行列、合并及数学结构；空题干不生成通用重复身份。保留“非语义近似去重”的限制。
- CLI、摘要和浏览器区分 succeeded、partial、failed，退出码分别为 0、3、1，题答待核验数量可见。

新产物为 `source-bank-v2`，位于 `evals/private/question-bank-v2/`。原文件及旧 `evals/private/question-bank/` 均不覆盖。共享业务 `contracts.py`、正式组卷算法与导出器未改；没有把源题目通过占位数据硬转为正式 Question。
